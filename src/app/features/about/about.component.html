About visualScience

visualScience surfaces recent, peer-reviewed scientific work — the discoveries themselves, the people who made them, and the universities, labs and companies behind them — with a direct link back to the original source for every entry.

Where the data comes from

Every discovery, researcher and institution profile is built from OpenAlex, a free, open catalog of scholarly works maintained by OurResearch. Data is refreshed daily by an automated job (see the source on GitHub) that queries OpenAlex for the newest journal articles across physics, biology, medicine, chemistry, computer science, mathematics, psychology, geology, environmental science, materials science and engineering, and republishes a curated snapshot to this site.

Why some things are missing

Very recently published papers sometimes haven't been matched to an author's institution yet by OpenAlex's automated pipeline — that researcher will still show up, just without an affiliation until a later refresh catches up. Abstracts are occasionally withheld by the publisher and aren't shown when that's the case; the "Read the source" link always goes to the original record regardless.

How this site is built

A static Angular application, with no backend: the daily data refresh commits JSON straight to this repository's /data folder, and the site reads it at runtime — so new discoveries appear without a redeploy. Hosted for free on GitHub Pages.
